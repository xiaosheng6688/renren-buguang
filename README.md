## 🚀 部署方式

同塔罗应用，零服务器部署：

**Cloudflare Pages（推荐，国内快）：**
1. 注册 [Cloudflare](https://dash.cloudflare.com)
2. Pages → 上传 `index.html`
3. 3 分钟上线

**Netlify：**
1. 注册 Netlify
2. 拖拽 `index.html` 到上传区
3. 自动 HTTPS
